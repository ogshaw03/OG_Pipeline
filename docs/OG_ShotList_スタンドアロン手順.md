# OG ショットリスト（スタンドアロン版）インストール・起動手順

Maya を持たない制作進行の方などが、各ショット／工程の最新動画を一覧・確認するための
独立アプリ（`OG_ShotList.py`）の導入・起動手順です。

- 一覧（グリッド／リスト）表示、工程バッジ、工程で絞り込み・並び替え
- タイルをダブルクリックで **元解像度ビューア**（フレーム送り／ブックマーク）
- プロジェクト設定（JSON）は本体ツールから受け取って取り込み可能

配布形態は2通りあります。**A. exe を受け取って使う（推奨・最も簡単）** と
**B. Python を入れて .py を動かす**。目的に合う方を選んでください。

---

## A. exe を受け取って使う（Python 不要・推奨）

パイプライン担当が用意した `OG_ShotList.exe` を使う方法です。

1. `OG_ShotList.exe` を任意のフォルダにコピーします（例: デスクトップ）。
2. ダブルクリックで起動します。
   - 初回起動時に SmartScreen の警告が出たら「詳細情報」→「実行」。
3. 起動メニューで対象を選びます（下記「起動後の使い方」へ）。

> exe には Python・PySide・OpenCV が同梱されているので、別途インストールは不要です。
> ネットワーク上の共有フォルダ（プロジェクトのパス）にアクセスできる PC で使ってください。

---

## B. Python を入れて .py を動かす（開発者向け）

### 1. 必要なファイル
同じフォルダに次の2つを置きます。
- `OG_ShotList.py`（起動用）
- `OG_Pipeline.py`（本体ライブラリ。ショットリストの中身）

### 2. Python の準備
- Python 3.7 以上を推奨（[python.org](https://www.python.org/) からインストール。
  Windows ではインストール時に「Add Python to PATH」にチェック）。

### 3. 依存ライブラリのインストール
コマンドプロンプト（またはターミナル）で:
```bat
pip install PySide2 opencv-python
```
- `PySide2`：必須（GUI）。うまく入らない場合は `pip install PySide6` でも動きます。
- `opencv-python`：任意。mp4 の埋め込み再生に使用。入れない場合は連番再生／外部プレイヤーになります。

### 4. 起動
```bat
python OG_ShotList.py
```

---

## 起動後の使い方

起動すると、最初に選択メニューが出ます。

| 選択肢 | 内容 |
|---|---|
| （プロジェクト名） | すでに登録済みのプロジェクトを開く |
| 📂 フォルダを直接開く… | 任意の「ショットフォルダの親」を指定して開く（この直下がショット） |
| ⭳ プロジェクト設定(JSON)を取り込む… | 本体ツールから受け取った設定 JSON を読み込む |

- プロジェクト設定 JSON は、パイプライン担当が本体ツールの
  **［プロジェクト設定］→［⭱ エクスポート］** で書き出したものです。受け取ったら
  「⭳ 設定(JSON)を取り込む…」で読み込むと、以降は一覧に表示され選ぶだけになります。
- 対象を選ぶと、全ショットの最新動画がグリッドで一覧表示されます。

### 画面操作
- 上部 **表示: ▦ / ≡** … グリッド／リスト切替
- **サイズスライダ** … タイルの大きさ（グリッド3〜7列／リスト5〜20行）
- **工程で絞り込み** … 特定工程の動画だけ表示
- **並び替え** … ショット名／工程順
- **⏸ 再生停止** … 全再生を止めてファイルロックを解放（この間は外部で削除／移動可）
- タイルを **シングルクリック** … 右サイドバーに工程別の最新動画
- タイルを **ダブルクリック** … 元解像度ビューアを開く

### ビューア（ダブルクリックで起動）
| キー | 動作 |
|---|---|
| Space | 再生 / 停止 |
| ← / → | フレーム送り（前 / 次） |
| ↑ | 前のブックマークへ |
| ↓ | 次のブックマークへ |
| F | 現在フレームをブックマーク（トグル） |

タイムスライダのドラッグでフレーム単位のスクラブができます。ブックマーク位置は
スライダ上に縦線で表示されます。

## exe を自分で作る（パイプライン担当向け）

配布用の exe は [PyInstaller](https://pyinstaller.org/) で作成します。

```bat
pip install pyinstaller PySide2 opencv-python
pyinstaller --noconfirm --onefile --windowed --name OG_ShotList ^
  --exclude-module PySide6 ^
  OG_ShotList.py
```
- 生成物: `dist\OG_ShotList.exe`（単体配布可）
- `OG_Pipeline.py` は自動同梱されます。されない場合は
  `--hidden-import OG_Pipeline` または `--add-data "OG_Pipeline.py;."` を追加。
- `--windowed`: 実行時のコンソール窓を出さない（デバッグ時は外すとログが見えます）。
- アイコンを付けるなら `--icon app.ico`。
- PySide2 と PySide6 の両方が環境にあると容量が増えるので、使う方だけ残し他方を
  `--exclude-module` で除外してください（上例は PySide2 を使用）。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| `ModuleNotFoundError: PySide2` | `pip install PySide2`（または PySide6）。exe 版なら不要 |
| 一覧に何も出ない | 「ショットフォルダの親」が正しいか確認。直下のフォルダがショットとして扱われます |
| mp4 が再生されず「外部で再生」になる | `opencv-python` を入れる（`pip install opencv-python`）。exe はビルド時に同梱 |
| プロジェクトが選べない | 設定 JSON を「⭳ 設定(JSON)を取り込む…」で読み込むか、「📂 フォルダを直接開く…」を使う |
| 共有フォルダにアクセスできない | ネットワークドライブ／VPN 接続を確認。パスにアクセスできる PC で実行 |
| 動作が重い | サイズスライダで列数を減らす／「⏸ 再生停止」で一時停止。連番より mp4 の方が軽いです |

---

## 補足
- このアプリは **閲覧専用**です（シーンの保存・書き出し等は本体ツール側の機能）。
- プロジェクトのパス（ショットフォルダ）は、本体ツールと同じ共有ストレージ上を想定しています。
