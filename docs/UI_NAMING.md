# UI 呼称リファレンス（バックログ）

このチャット／今後の指示で、UI の各ウィンドウ・パネルをどう呼ぶかの取り決め。
指示を明確にするための共通語彙。

---

## A. メインウィンドウ（`OG_Pipeline` 本体 / `OGPipelineWindow`）
呼称: **「メインウィンドウ」**

```
┌─────────────────────────────────────────────┐
│ ① ヘッダー        OG_PIPELINE / …  ▸ルート表示│
├─────────────────────────────────────────────┤
│ ② ルートバー   PROJECT:[▼] ★次回 ＋追加 …全ショット動画│
├─────────────────────────────────────────────┤
│ ③ 検索バー    [🔍 検索………]  ◎現在のシーン ↻│
├──────────────────────────┬──────────────────┤
│ ④ ブラウザ（Millerカラム） │ ⑤ 詳細パネル        │
│   …カラム / アイテム      │   ├ プレビュー       │
│   ⑥ ファイル操作バー       │   └ ファイル情報     │
├──────────────────────────┴──────────────────┤
│ ⑦ ステータスバー            準備完了 [progress]│
└─────────────────────────────────────────────┘
```

| # | 呼称 | 内容 |
|---|---|---|
| ① | **ヘッダー** | 上部のタイトル帯（OG_PIPELINE ロゴ／右にルートパス表示） |
| ② | **ルートバー** | PROJECT プルダウン、★次回も使用、＋追加／インポート／エクスポート、🎞全ショット動画、🎬mp4有効化 |
| ③ | **検索バー** | ファイル検索欄＋「◎現在のシーン」「↻REFRESH」 |
| ④ | **ブラウザ**（または「カラムブラウザ」） | 左側の Finder 風 Miller カラム。横方向の各列＝**「カラム」**、その中の項目＝**「アイテム」** |
| ⑥ | **ファイル操作バー** | ブラウザ下部の「📂フォルダを開く／⤓SAVE AS／⇧VERSION UP」 |
| ⑤ | **詳細パネル** | 右側。上の動画領域＝**「プレビュー」**、下＝**「ファイル情報」** |
| ⑦ | **ステータスバー** | 最下部のメッセージ＋進捗バー |

## B. 全ショット動画ウィンドウ（`AllShotsDialog`）
呼称: **「全ショットウィンドウ」**（または「グリッドウィンドウ」）

```
┌─────────────────────────────────────────────┐
│ ⓐ ソートバー   ◈ALL SHOTS        並び替え:[▼] │
├──────────────────────────────┬──────────────┤
│ ⓑ グリッド（5×5タイル）        │ ⓒ 工程サイドバー│
│   [タイル][タイル][タイル]…    │  [工程タイル]   │
│   …                          │  [工程タイル]   │
├──────────────────────────────┴──────────────┤
│ ⓓ フッター   動画あり N/M ショット …          │
└─────────────────────────────────────────────┘
```

| # | 呼称 | 内容 |
|---|---|---|
| ⓐ | **ソートバー** | 上部の「ALL SHOTS」タイトル＋並び替えプルダウン |
| ⓑ | **グリッド** | 左側のタイル一覧。各マス＝**「タイル」** |
| ⓒ | **工程サイドバー**（略して「サイドバー」） | 右側。タイル選択で工程別の最新動画が並ぶ。中の各マス＝**「工程タイル」** |
| ⓓ | **フッター** | 最下部の件数表示 |

### タイル内の各部の呼称
| 呼称 | 内容 |
|---|---|
| **タイトル（ショット名）** | 左上の名前 |
| **工程バッジ** | 右上の色付きラベル（lay_pri 等） |
| **プレビュー領域** | 中央の動画／連番表示部 |
| **再生/停止ボタン** | プレビュー右下の小さな ▶/⏸ |
| **工程ボタン** / **開くボタン**（📂 開く） | タイル下部のボタン |

## C. リファレンス編集ダイアログ（`ReferenceEditDialog`）
呼称: **「リファレンス編集ダイアログ」**

シーンを開かずに `.ma` の参照を編集する画面（右クリック→編集で表示）。
各行＝**「リファレンス行」**、上部の一括置換部＝**「一括置換バー」**。
